# 0.1.2

- 修复小米电脑客户端路径带 Windows 盘符或本地缓存前缀时，登录及后续接口误发到 NAS 根 `/api` 的问题；统一提取本插件 `/plugin/<UID>/bililivereplay/api` 路径，兼容数字和 `u` 前缀 UID。
- 登录提示区分密钥错误、NAS 访问拒绝、缺少观看接口、Docker 无法连接和异常响应；两次接口验证通过后才保存密钥，登录检查有超时限制。
- 增加 `/D:/plugin/...` 和 `/C:/plugin/u...` 桌面入口下的真实后端登录回归，验证错误密钥后的重试及接口路径；保留手机、日历、播放进度、连播和原数据库保护测试。
- 保留 v0.1.1 的每两分钟恢复与安全回滚，无需更新 Docker 镜像。

# 0.1.1

- 新增独立 cron 任务，每两分钟检查应用市场清理后的插件目录、静态入口、图标、用户注册、端口及 Nginx 代理，从 `/data` 备份补回缺失内容；同时补齐部分删除的页面文件。
- 保留开机恢复，直接维护本插件的 systemd wants 链接；安装、恢复、升级及回滚不调用 `systemctl`，避免 NAS 交互会话或恢复服务中的 D-Bus 等待死锁。
- 回滚先持久化停用状态、移除本插件定时任务和开机链接，再撤销插件配置；已排队的恢复任务因状态和互斥锁而跳过，回滚失败时也保持恢复停用。
- 定时恢复合并本插件缺失条目，不覆盖其他插件、用户修改或冲突 ID；检测到共享配置并发变化时停止本次恢复并等待下次检查。
- `status.sh` 增加任务配置状态、最近恢复检查时间和失败原因；每次只保存一条检查结果，避免日志无限增长。
- 支持从 v0.1.0 升级和退回旧版页面；退回时保留新版安全恢复脚本。安装包附更新后的部署、恢复与回滚说明。
- 不增加 WebDAV 上传、socat 连接工具，不修改 Docker、录像、原数据库或观看进度。

# 0.1.0

- 独立 NAS 观看前端，复用主播卡片、日历、场次播放器、弹幕、自动连播和播放进度同步。
- 手机底部场次面板、电脑场次弹窗；日期内可直接将任一整场标记已看，保留各段播放位置并刷新日历状态。
- 相对静态资源路径和插件专用 API 前缀，无 Docker 网页代理、无地址改写注入；登录存储与 NAS 其他页面隔离。
- 支持浅色、深色、自动主题及手机全屏横屏兼容。
- 新插件独立注册，可与原代理插件共存，共享现有独立观看数据库。
- 预编译 ZIP、一键安装和升级、上一版回退、失败自动恢复、共享配置备份及重启恢复。
